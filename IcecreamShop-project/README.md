# 🍦 Online Ice Cream Shop

## About the Project

The Online Ice Cream Shop is a Java-based project developed to make ordering ice cream easier and more convenient. Customers can choose their preferred ice cream flavours and toppings, enter their delivery details, select a delivery time, and calculate the total price of their order.

The idea is to provide a convenient alternative to renting a physical shop or an ice cream truck, making the ordering process simpler and more cost-effective.

## Features

Customer Details: Collects the customer's name, phone number, location, email, and allergy information.

Ice Cream Selection: Offers Vanilla, Chocolate, Strawberry, Mango, and Matcha flavours.

Toppings: Allows customers to choose toppings such as strawberries, chocolate chips, sprinkles, and caramel sauce, or select none.

Price Calculation: Calculates the order price based on the number of scoops and toppings.

Delivery Preferences: Allows customers to enter their preferred delivery time.

Payment Selection: Provides cash and card payment options.

Receipt Generation: Displays an order summary, including the customer details and total price.

Graphical User Interface: Uses Java Swing to launch a graphical interface.

## OOP Concepts Demonstrated

Encapsulation: Customer attributes are declared private and accessed through getter and setter methods.

Constructor Overloading: The Customer class has a default constructor and a parameterized constructor.

Classes and Objects: The project uses separate Customer and Order classes.

Methods: Methods are used to display customer information and calculate order prices.

Control Structures: Loops and conditional statements manage customer choices and payment selection.

## How to Run

Install the Java Development Kit (JDK).

Clone or download this repository.

Open the project in an IDE such as NetBeans, IntelliJ IDEA, or Eclipse.

Ensure all Java files are in the correct package or source folder.

Run ICECREAMSHOP.java, which contains the main() method.

## Project Purpose

This project was developed as a practical exercise in Java programming and object-oriented programming. It demonstrates how classes, objects, constructors, encapsulation, collections, loops, and conditional statements can be used to build a simple ordering system.
