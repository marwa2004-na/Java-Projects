# Java Projects

A collection of Java programming projects developed during my studies at the University of Technology and Applied Sciences (UTAS). These projects demonstrate my understanding of object-oriented programming, graphical user interfaces, data structures, and algorithmic problem-solving.

## Projects

### 1. Online Ice Cream Shop

A Java-based ice cream ordering application that allows customers to select flavours and toppings, enter their delivery details, choose a payment method, and calculate the total cost of their order.

### Key Features
- Customer information and allergy details
- Ice cream flavour and topping selection
- Order price calculation
- Delivery time preferences
- Cash and card payment options
- Order summary and receipt display
- Graphical user interface built with Java Swing
  
### Technologies and Concepts
- Java
- Java Swing
- Object-Oriented Programming (OOP)
- Classes and objects
- Encapsulation and constructor overloading
- ArrayList, loops, and conditional statements


### 2. Polynomial Operations Using Linked Lists

A Java data structures and algorithms assignment focused on representing and manipulating mathematical polynomials using a singly linked list.

The assignment covers operations on two polynomials of arbitrary degree, including arithmetic calculations and term manipulation.

### Key Operations
- Read and display two polynomials
- Add two polynomials
- Multiply two polynomials
- Multiply a polynomial by a constant (scalar multiplication)
- Insert a term with a specified degree
- Search for a term of a given degree
- Check whether two polynomials are equal
- Calculate the inverse of a polynomial, if implemented

### Technologies and Concepts
- Java
- Data Structures and Algorithms
- Singly linked lists
- Nodes and pointers/references
- Polynomial representation
- Traversal, insertion, and searching
- Mathematical operations and algorithmic problem-solving

### Tools and Technologies

- Java
- Java Development Kit (JDK)
- Java IDEs
- Java Swing
- Object-Oriented Programming
- Data Structures and Algorithms
